# Package memory

```go
import memory "github.com/grx-gql/grx/in-memory"
```

`memory.New()` creates an in-process implementation of
`github.com/grx-gql/grx/pubsub.PubSub`.

See the [pub/sub concept guide](/concepts/pubsub) for usage and backend
selection guidance.
