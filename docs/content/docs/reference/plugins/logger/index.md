## type Config [#Config]

Config configures a [Logger](<#Logger>). Logger is required.

```go
type Config struct {
    // Logger is the slog logger used to emit lifecycle events. The
    // plugin attaches the request context to every log call so that
    // per-request fields propagated via the context are preserved.
    Logger *slog.Logger
}
```

## type Logger [#Logger]

Logger is a [plugins.Plugin](<https://pkg.go.dev/github.com/grx-gql/grx/plugins#Plugin>) that emits a structured log entry at every stage of the GraphQL request lifecycle. It embeds [plugins.Base](<https://pkg.go.dev/github.com/grx-gql/grx/plugins#Base>) and therefore satisfies the full Plugin interface.

```go
type Logger struct {
    plugins.Base
    // contains filtered or unexported fields
}
```
